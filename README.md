# Use LeafLabs Maple handbrakes as axis

## Requirements

- xboxdrv (̀`sudo apt install xboxdrv`)
- python3

## Run in a bash shell

```bash
python3 -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip
pip install -r requirements.txt

python main.py
```

## Run in a fish shell

```shell
python3 -m venv .venv
source .venv/bin/activate.fish

python -m pip install --upgrade pip
pip install -r requirements.txt

python main.py
```
